5 системных корней (лечим классы, не симптомы)

1. Нет флот-манифеста версий
Пути (C:/D:/E:), Device ID, имена машин, версии скриптов дрейфуют. Фикс едет туда, где шла отладка; раскладка на памяти → propagate нарушен ≥3 раза.
Лечение: манифест «компонент→версия→машина» + ночная хэш-сверка (расширить /arch до флота).
2. Сторожа без предохранителя
Watchdog убивал Syncthing по ложному 403 (пила 18 сек, 2 машины); tick лидера спамил self-ACCEPT ×18; heartbeat «38/40 🔴» при живых задачах.
Лечение: circuit-breaker каждому сторожу + «красный вердикт = 2 независимых источника до действия».
3. «Жив» ≠ «несёт службу»
Роботы тикают, но не исполняют обязанности: тикал — не отвечал; heartbeat зелёный — архиватор мёртв 8 дней.
Лечение: heartbeat v3 = дата последнего УСПЕХА по каждой обязанности (архив/respond/ACK/бэкап).
4. Протокол считает всех always-on
Always-on только хаб. Ноут и Мак спят → предложения консенсуса умирают по таймауту об спящих.
Лечение: классы узлов (always-on/спящий) с разными SLA + durable-очередь приказов до пробуждения.
5. Шум хоронит сигнал
~90% чата 03 = heartbeat/алерты. QQQ-запросы к Антону тонут в спаме роботов.
Лечение: heartbeats в отдельный поток / почасовой rollup; 03 = только события и вопросы.
