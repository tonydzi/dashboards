Что закрыто по находкам внешней панели (Codex · Grok · Gemini, 3/3)

  • Цикл починка→починка: сессии починки не журналируются вовсе
  • Повторные Stop одного прогона: штамп «сессия+класс», дверь дёргается один раз
  • Гейт со словами семьи в тексте: отдельный тест + мутация, которая краснеет при выключенном фильтре

Честные границы

  1. Жёстко убитый прогон невидим: нет конца сессии — нет личинки. Этот слой держат stale_task_watch.py и os_task_watchdog.ps1.
  2. Самоперезаписи кода нет. Личинка только называет класс; правку предлагает сессия починки — человек в петле сохранён намеренно.
  3. Полную расшифровку голосовой прочитать не удалось: MCP телеграма молчал по 300 с дважды. Работал по дословной цитате из сида; строка в журнале заведена.
