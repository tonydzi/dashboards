4. Агрегаторы «все подписки в одном интерфейсе» — что реально существует

Главный вывод, который ломает ожидание. Продуктов, которые подключают твои уже оплаченные подписки (ChatGPT Plus, Claude Max, SuperGrok, GLM-план) и гоняют задачи через их собственные лимиты, в честном готовом виде нет. Всё, что рекламируется этими словами, делится на три семейства — и ни одно не делает ровно то, что ты просил.

Семейство A. Перепродавцы («одна подписка — все модели»)

Кто: Mammouth.ai (€10–60/мес), Aizolo (~$9.9/мес), Aymo/Geeky.chat (до $12/мес), MultipleChat, Poe.
Как устроено: компания сама покупает API у OpenAI/Anthropic/Google и продаёт тебе доступ пачкой. Улика: на mammouth.ai прайс идёт «GPT/Claude/Gemini по €20/мес каждая», ни слова про подключение своего аккаунта или своего API-ключа.
Минус, который убивает: это одиннадцатая подписка поверх твоих десяти. Твои лимиты не используются вообще. Истории чатов из твоих аккаунтов там не видно.

Семейство B. Клиенты на своих API-ключах

Кто: Cherry Studio, Chatbox, Msty, LibreChat, Open WebUI, 5ire, Jan, LM Studio (последний — только локальные модели).
Как устроено: красивое единое окно, переключение моделей одной кнопкой, история локально. Но модель дёргается по API-ключу.
Минус: API-ключ — это оплата за токены, отдельный кошелёк. Подписочные лимиты (Plus / Max / SuperGrok) через API не работают — это два разных счёта у одного вендора.
⚠️ Отдельно: с 19.02.2026 в ToS Anthropic прямо записано, что OAuth-токен подписки Free/Pro/Max нельзя использовать в сторонних инструментах (исполнение с 04.04.2026). То есть «подключить свою подписку Claude в чужой клиент» — не серая зона, а прямой запрет.

Семейство C. Оболочки поверх веб-сессий — единственные, кто реально ест твои подписки

Кто: ChatALL (open-source, Apache-2.0), WebCatalog, Wavebox, Rambox, Shift.
Как устроено: внутри одного окна открывается настоящий веб-интерфейс каждого сервиса, ты логинишься своим аккаунтом → работают твои подписочные лимиты, видна твоя настоящая история чатов. ChatALL умеет ещё и разослать один промпт сразу во все и показать ответы рядом.
Честные минусы:
  • Хрупкость. Сами авторы ChatALL пишут, что веб-подключения держатся на реверс-инжиниринге интерфейсов и «регулярно ломаются», и рекомендуют API там, где он есть.
  • Безопасность — главное. Такое приложение держит у себя cookie-сессии всех твоих AI-аккаунтов сразу. Плюс ChatALL: он open-source, «вся история, настройки и данные логина хранятся локально на твоём компьютере», ничего не уходит на чужой сервер — это проверяемо. Минус любого закрытого аналога: проверить это невозможно.
  • Красная линия: любой продукт, который просит ввести пароли от твоих AI-подписок (а не залогиниться внутри его окна на официальной странице вендора) — отказ без обсуждения. Это выдача ключей от десяти аккаунтов третьей стороне. Наши пароли живут в secrets\ и наружу не уходят.
Рекомендация. Начать с ChatALL — единственный из списка, который (а) бесплатный и open-source, (б) хранит логины локально, (в) реально гоняет через твои подписки, (г) умеет «один вопрос → все модели рядом», что закрывает твоё «видеть глазами». Ставить только с официального репозитория github.com/ai-shifu/ChatALL. Если хочется просто аккуратных отдельных окон без общей корзины — WebCatalog (каждый сервис в своей песочнице Chromium, сессии изолированы).
Не рекомендую покупать Mammouth/Aizolo: платить одиннадцатый раз за то, что уже оплачено десять раз.
Замечание: у тебя на HP17 уже стоит All-in-One Messenger — это ровно тот же класс (семейство C), только для мессенджеров. Логика та же.

5. «Хочу глазами видеть, как ведутся сессии в Gemini / Grok / Codex / GLM»

Это другая задача, чем агрегатор чатов, и решается другими инструментами — оркестраторами параллельных агентных сессий:
  • Claude Squad (~7.5k★, Go) — TUI, tmux + git worktree, умеет Claude Code, Codex, Gemini, Aider в одном экране;
  • Conductor (macOS) — параллельные Claude Code / Codex агенты, каждый в своём worktree, дифф-ревью;
  • Crystal, Sculptor (Docker-изоляция), Omnara ($9/мес, смотреть с телефона);
  • Vibe Kanban — не брать: Bloop закрыл проект 10.04.2026, живёт только как community-форк.
Источник — наш же прошлый ресёрч (§6). Отдельная развилка: у нас уже есть своя видимость сессий (/sessions, FleetView). Если хочется картинку, а не список — скажи, соберу дашборд живых сессий по всем узлам.
