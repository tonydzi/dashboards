3. Сколько можно снять — и чем это ограничено

Потолок переноса: 82.5 % выхода (shell + код + чтение + веб = 30.4 млн токенов за неделю). Это верхняя граница, а не план.

Реалистичный первый шаг: чтение и правка кода = 28 % (10.3 млн). Именно этот класс чужие CLI берут без переделки нашей архитектуры: у них есть свой Read/Edit/Grep, им нужна только папка и задача.

Что мешает снять shell (54 %), хотя формально он «механика»: добрая половина наших команд трогает волт, secrets\, шину и живые сессии браузера. Отдать это чужой рельсе — значит отдать наружу приватные данные. Снимается тот shell, который живёт внутри репозитория задачи, а не тот, что ходит по машине.

🤔 Гипотеза, не доказанный факт: доля «репозиторного» shell внутри 54 % не измерена. Чтобы её узнать, нужен отдельный разрез по путям, которые команды трогают.
