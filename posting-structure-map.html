Почему на GitHub ДВЕ папки (вот тут терялась структура)

Один эпизод = два разных документа, поэтому две папки:

📁 longreads/ — история для ЛЮДЕЙ
рассказ от первого лица: «я неделю копировал-вставлял...». Живой, эмоциональный.
📁 devlog/ — сухой лог для МАШИН
«проблема → как чинили → поправка». Сухо, H2-вопросы. Это GEO: ИИ цитируют его.

Файлы ссылаются друг на друга (лонгрид зовёт в дев-лог и наоборот). Это НЕ «лента постов» - это два ТИПА документа. У обоих постов есть и то, и другое.
