Цикл DR — 7 обязательных шагов

1
Дедуп перед квотой
grep реестра _DR-Registry.md по теме/ID. collected/synthesized = стоп, бери готовое. Та же тема issued = переиспользуй номер.
2
Номер до промпта
dr_registry.py new → формат v4 DRYY-MM-DD-МАШИНА-NN-HHMM. Руками ID не сочинять (коллизии). В речи — только полный ID с датой.
3
Промпт paste-ready в чат
Полный текст в блоке text, ID первой строкой + ссылка на чат сразу. Приватный URL, публичный share ⛔.
4
Веер на 3 вендора
ChatGPT + Gemini + Grok, без спроса, квоты не экономим. Кворум 2 из 3 валиден для синтеза.
5
Проба-после-старта
«Вставка ≠ отправка ≠ старт». Доказательство: URL сменился на /c/-вид + крутится индикатор. Скриншот — финальный судья.
6
Ссылки сразу
Приватные URL чатов Антону сразу после старта, не дожидаясь отчёта. URL — и в строку реестра.
7
Сбор с доказательством + синтез
collected только при фактическом файле в _originals\deep-research\ (size>0, не «клик Export»). Затем insight-DR-* + Decision Memo.

Лестница съёма отчёта из Chrome

1
get_page_text → сохранённый дамп. Главная рабочая ступень: харнес кладёт файлом, вырезать тело по якорям Python. ⚠️ режет ~50k — сверять якорь КОНЦА.
2
Backend JSON (только ChatGPT): /backend-api/conversation/<id> с Bearer — минуя sandbox-iframe.
3
DOM через JS + копилка window.__x: большой текст в window-переменную, вынимать срезами.
4
Тупики без фокуса окна (проверены, не тратить время): execCommand copy=false · Ctrl+C→буфер пуст · blob-download молча блокируется · вброшенная кнопка ≠ user gesture. Обход клика: программный .click() — React ловит.
5
Ничего не сработало → не молчать: дать Антону URL чата и точное место, откуда забрать руками.
