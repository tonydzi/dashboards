## 2. Что это за продукт

Детерминированный «движок-мозг» на одной структуре данных — **Adelic Tree** (гиперболическое дерево, модель Пуанкаре). Одна структура одновременно работает как БД, индекс, вектор-поиск, ML-рантайм и решатель. Позиционирование: «Physical AI infrastructure based on geometry of computation». Бинарь **<10 МБ**, только CPU, без GPU и внешних зависимостей, всё считается локально.

**Четыре заявленных отличия:**
1. ноль галлюцинаций — детерминизм, тот же вход даёт тот же выход
2. заменяет вектор-БД + эмбеддинг-модель + граф-БД одним вызовом
3. ~10 МБ, любой CPU вплоть до микроконтроллера
4. white-box: формула и R² на каждый прогноз

**Шесть слоёв цикла Sense → Understand → Decide → Act → Verify → Adapt (~34 эндпоинта):**

- **Sense** — `seed`, `insert`, `feed_text`, `cognitive/observe`
- **Understand** — `query_text`, `search`, `nearest`, `discover`, `reason`, `connectome/decompose`
- **Decide** — `cognitive/predict`, `solveCSP`, `geometry_solve`, `graph_solve`, `quantum_tree_solve`, `solve/math`, `solve/optimize`
- **Act** — `holo_exec`
- **Verify** — `cognitive/evaluate`, `anomaly`, `missing`, `tree`, `get`
- **Adapt** — `cognitive/feedback`, `cognitive/learn`

**Holo Language** — тьюринг-полный язык с «человеческим» синтаксисом, исполняется на сервере одним вызовом `/api/holo_exec`. Состояние живёт в дереве, есть сессии (переживают рестарт), функции, циклы, try/catch, HTTP-вызовы. Сделан явно под AI-агентов: агент описывает логику, сервер исполняет за один round-trip.

**Модели поставки:** MCP (лицензия на машину, device binding) · On-Prem (enterprise) · IoT/Edge. Бесплатно для науки и образования. **Цен нет** — «by request».
