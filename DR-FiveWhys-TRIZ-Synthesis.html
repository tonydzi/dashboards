2. Две дыры, которые оба плеча нашли независимо

Дыра 1 · ложная склейка класса

«Все проблемы с браузером» — ярлык по симптому. Склеили по внешнему сходству → уверенно нашли фальшивый общий корень.

  • Тест общего механизма: тот же путь в коде / сигнатура лога / срок жизни токена?
  • Тест замещения: если бы корень был устранён, этот инцидент всё равно бы случился? Да → он не в классе.
  • Двое размечают вслепую; разошлись — класс считается ложным.
  • Детектор жадности: доля отклонённых классов > ~30% → склейка слишком широкая.

Дыра 2 · линейная цепочка

«Почему? почему?» идёт по одной ветке. В разборе Card (BMJ 2017) так нашли 2 причинных пути из 30.

  • Вопрос меняется на: какие условия должны были совпасть одновременно?
  • Выход — список условий, а не цепочка; каждое с меткой доказано/гипотеза.
  • Живой спор оставлен: STAMP/Safety-II вообще отрицают единственный корень в сложных системах.

4. ТРИЗ: три плеча, одна рекомендация

Доказательная база

  • Обзор 2016: развитие ТРИЗ «никогда не проходило обычной научной валидации»
  • Попадание матрицы противоречий — 27–50%, ретроспективно
  • Intel $212.5M и Samsung $100M+ — самоотчёт заинтересованных
  • В софте/SRE: обзор 2019 — «в самой начальной фазе», к 2026 без изменений

Что берём

  • Противоречие → четыре разделения → ИКР → тримминг
  • Цена входа 2–8 часов; без матрицы, Су-поля, АРИЗ, сертификации
  • Применяем к тому же порогу рецидива, не к каждому багу
  • Статус: тень с замером 30 дней

Конфликт с АК-47 — реальный

  • Идеальность максимизирует функций на деталь
  • АК-47 максимизирует диагностируемость на деталь
  • Тримминг — ложный друг: не удаляет функцию, а перекладывает → рост связности
  • Красный список: вложенность, универсальность, посредник, обратная связь, самообслуживание

5. Единственный случай, где ТРИЗ дала неочевидный ход

Из четырёх наших живых противоречий три ТРИЗ просто пересказала (сторож на другой машине · pull вместо push · персистентный профиль). Заработала она один раз:

«Тихий индикатор против тишина ≠ живой». ИКР — «индикатора не существует, но функция выполняется» — заставляет прийти к dead-man's switch: отсутствие пульса и есть тревога, зелёной лампочки, способной самой умереть, больше нет. Два плеча из трёх назвали именно этот случай единственным неочевидным. Это ровно наш класс «зелёный индикатор — мёртвый конвейер», который в чужой статье 2026 года называется fail-plausible.

7. Честная граница этого синтеза

  • Кворум 4/6 по телам НЕ набран. По ТРИЗ живых плеча четыре, по 5 Why — три. GLM по 5 Why приехал пустым (в файле только промпт). Браузерное плечо ChatGPT снять не удалось: Chrome-MCP на хабе не подключён, других поверхностей с куками для chatgpt.com на узле нет.
  • Четвёртое плечо добрано обходной рельсой того же вендора — Codex CLI headless, без браузера, 313k токенов на прогон. Его выводы внесены дельтой поверх первой редакции, синтез не переписывался. Оговорка: это не тот же продукт, что браузерный Deep Research, — режим поиска другой.
  • Честно не доказано и в источниках: что разбор по классу снижает рецидив сильнее поштучного. Направление верное, контролируемых замеров почти нет.
  • Сильнейшее возражение против ТРИЗ-минимума оставлено в полный рост: подмножество никем не проверялось как подмножество, есть риск принять «плацебо с советским брендингом».
