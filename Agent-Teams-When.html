🚀 Готовые промпты (вставляй после рестарта Claude Code)

1 · Сравнение «X vs Y» — под Whisper/GPU/MCP/LLM
Команда из 2 тиммейтов на Sonnet, read-only, без записи файлов:
- champion-X: собери сильнейшую сторону варианта <X> (бенчмарки, цена, риски).
- champion-Y: то же для <Y>, и оспорь цифры champion-X.
Обменяйтесь напрямую, один раунд челленджа, НЕ ищите консенсус — сохраните разногласия.
Затем ты (лид) дай рекомендацию с условиями «бери X если…, Y если…».
2 · Alpha-анализ чата/сообщества — под Fox/Lobster/Telegram
Команда из 3 тиммейтов на Sonnet, read-only (источник — <chat.db / выгрузка>):
- pricing: как тут устроено ценообразование/сделки.
- trust-map: кто гарант/хаб доверия, кто скамил.
- roster: ключевые игроки и их роли.
Если кто-то нашёл, что один человек = центр (гарант), пусть СРАЗУ скажет другим —
это меняет их разбор. Лид собери единую alpha-сводку.
3 · Стратегическое решение / R+DR — под cofounder/архитектуру
Команда из 2 тиммейтов на Sonnet, read-only, без записи и без отправки наружу:
- advocate: сильнейшие доводы ЗА <идею/подход> и сценарии-победители.
- skeptic: доводы ПРОТИВ, скрытые риски, где это дороже/хуже; оспорь advocate.
Один раунд челленджа, сохраните разногласия (НЕ консенсус). Лид → вердикт
«когда да, когда нет» одной таблицей.

🧰 Микро-плейбук (если включаешь команду)

  • Включено: CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 (на хабе) — но нужен рестарт сессии.
  • Только read-only · 2–3 тиммейта макс (не «3–5» из доков) · все на Sonnet.
  • Один присест — нет /resume тиммейтов; не гонять длинные сессии (на Windows баг порчи identity лида после compaction).
  • Управление in-process: ↑↓ выбрать · Enter написать · x стоп · Ctrl+T задачи.
  • НЕ просить «консенсус» — сохранять разногласия (сикофантия рушит правильные позиции).

💸 Правда про цену

  • ≈ 1–2.1× токенов против одиночной сессии · 1.3–2.9× против Workflow-оркестратора.
  • Премию гонит размер контекста (каждый тиммейт грузит свою копию), не «ум».
  • Счётчик parent-сессии не считает дочерние → реальная цена выше, чем кажется.
  • Официальный якорь: ~7× в plan-mode; на коде бывало +73–124% без выигрыша качества.
